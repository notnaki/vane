Docs

Vane is a native macOS browser in the shape of Arc, built on WebKit. This page is how it works day to day.

Getting started

  • Install. brew install --cask notnaki/tap/vane, or download the DMG from the latest release and drag Vane to Applications. Builds are signed and notarized. Requires macOS 26 or later.
  • Default browser. Vane offers once to become the default; later it is Sites → Make Vane the Default Browser. Links from Mail, Slack and open -a Vane land in a tab.
  • Address bar. ⌘L or ⌘T opens the bar over the page. It decides between navigation and search: bare hosts, localhost:3000, IPs, file paths and ~/ paths navigate; anything else searches. A leading !g, !ddg, !b picks a search engine for that one query. Suggestions come from history and bookmarks.
  • Coming from Arc? See Import from Arc. Profiles, Spaces, pinned tabs, favourites, passwords and logged-in sessions all come across.

The sidebar

Top to bottom: the address pill, the Favourites grid, the Space's name, its Pinned section, the Tidy | Clear divider, the Today tabs, and the footer with the Space dots.

  • Favourites are the tiles at the top. They belong to the profile, so they stay put while you switch Spaces. Drag a row onto the grid to make one; drag a tile back into the list to remove it. Closing a favourite (⌘W) sends it back to the page it was favourited at rather than closing it.
  • Pinned tabs live between the Space name and the divider. A pinned row keeps the name it was pinned under, whatever page it wanders to. Hover the favicon of a wandered row and it becomes a return arrow: click it to go back to the pinned page. The × is a two-step: first press sends the row home, second press unpins it.
  • Folders can hold rows in Pinned and in Today. Nest them, fold them, rename them, drag rows in and out. Dragging a whole folder across the divider moves its tabs between Pinned and Today.
  • Today tabs are the ordinary ones. They auto-archive after a while; the Archive is in the Library (⇧⌘L). Clear archives all of them at once and Tidy groups them into named folders using the on-device model, with one Undo.
  • Renaming. Double-click a row to rename it. A name you type wins over everything and survives an unpin. "Use the Page's Own Title" in the row's menu removes it.

Spaces

  • Switching. Swipe horizontally on the sidebar with two fingers, use ⌥⌘→ / ⌥⌘←, ⌃1–⌃9, or click a dot in the footer. The page changes the moment the swipe commits.
  • Creating. On the last Space, keep pulling left: a plus at the sidebar's edge fills, then the circle behind it fills solid, and you land on Create a Space with a name field, a profile, and a theme. Swipe right or press ⎋ to cancel. Spaces → New Space… does the same from the menu.
  • Theme. Right-click the Space name or its dot for the theme editor: colours, a gradient, grain, and light or dark. The whole window takes the colour.
  • Kept alive. A window keeps the Spaces it has visited loaded behind the one on screen, so swiping back puts the same pages in front of you. Idle pages are unloaded on the usual clock and come back exactly where they were.
  • Library. ⇧⌘L shows every Space and the Archive, and lets you move Spaces between profiles.

Live Folders

A Live Folder is a pinned folder that fills itself. Today it has one source: GitHub pull requests.

  • Make one from the Space name's menu or the dot's menu: New Live Folder…. The first time, Vane signs you in to GitHub in a tab; one click, no token to paste. A build from source without the OAuth secret asks for a personal access token instead.
  • What it shows. Every open pull request you are involved in, or one repository's, optionally only the recent ones. Rows appear and vanish as pull requests open and close; a row you take out stays out. Each row is named after its pull request.
  • Refresh. Every five minutes, when the folder is unfolded, and on Refresh Now. A folder that GitHub refuses says so in a toast; if GitHub has revoked the sign-in Vane forgets it and Edit Live Folder offers to connect again.

Import from Arc

File → Import from Arc… brings a whole Arc installation across in one go.

  • What comes across. Every Arc profile becomes a Vane profile (Arc's default maps to Vane's). Each Space arrives with its name, theme colour, pinned tabs, folders, live folders, and Today tabs; the profile's favourites fill the grid. Passwords and logged-in sessions are decrypted with Arc's own key and saved into the matching profile. History and bookmarks come too.
  • How. Pick Arc's folder in the panel (it opens there). Vane shows what it found; press Import. macOS asks once to let Vane read Arc's Safe Storage key; allow it, or passwords and sessions are skipped and the toast says so.
  • Safe to repeat. Arc can stay open. Running the import again skips Spaces, passwords and bookmarks that are already there. Nothing in Arc is written.

Other imports

  • History and bookmarks from Chrome, Chromium, Edge, Brave, Vivaldi, Opera, Arc, Firefox and Safari: File → Import History & Bookmarks…. Read-only.
  • Passwords from a CSV export of Chrome, Edge, Brave, Opera, Vivaldi, Arc, Firefox, Safari, macOS Passwords, 1Password or Bitwarden: Passwords → Import Passwords….

Passwords

  • Saved as ordinary Internet keychain items, per profile, that only Vane can read. Nothing syncs.
  • Autofill offers only over https and never submits for you. ⌥⌘L fills the focused form; with several accounts saved, a chooser appears on the field.
  • Manage Saved Passwords… opens the list; deleting there deletes the keychain item.

Privacy and blocking

  • Ad and tracker blocking uses WebKit's own declarative blocker, so blocked requests never leave the machine and nothing is injected into pages. On by default, per profile: Sites → Block Ads and Trackers. Add Filter List… accepts EasyList-style files from disk.
  • Private windows (⇧⌘N) get a data store that is never written to disk.
  • Camera and microphone are asked per site and remembered per host; Reset Camera & Microphone Permissions… forgets them.
  • Certificates. A bad certificate shows a two-step alert with the fingerprint; an exception is tied to that exact certificate, so a swapped one asks again.
  • Profiles keep everything apart: data store, history, passwords, favicons, pins, session, extensions and Spaces.

Little Vane and splits

  • Little Vane (⌥⌘N) is a small single-page window for a quick look, the way a link from another app opens. Its menu can move the page into your main window.
  • Split view. ⌃⇧+ puts a second page beside the current one; up to four panes in one card, one row in the sidebar. ⌃⇧N moves between panes and ⌃⇧_ removes the split.
  • Picture in picture (⌥⌘P) detaches the page's video; a tab playing in that window is never unloaded.
  • Reader (⌥⌘R) shows the article alone, with adjustable size and a serif toggle.

Keyboard shortcuts

Every one of these can be rebound in Settings → Keyboard. AppKit's own chords (⌘C, ⌘Q, ⌘H and friends) are left alone. ⇧⌘P searches commands by name or by shortcut.

Developer

  • Extensions. Extensions → Install Extension… takes an unpacked MV2 or MV3 extension folder containing manifest.json, one set per profile.
  • Inspector. Web Inspector (⌥⌘I), JavaScript console (⌥⌘C), View Source (⌥⌘U), a user-agent picker, and Allow Web Inspector for pages.
  • Build from source. swift build -c release && ./make-app.sh on macOS 26. ./.build/release/vane selfcheck --pure runs the offline checks. The README has the rest.

Updates

Vane checks for a new release on launch and then quietly; when one is ready a toast waits for you, and one click swaps in the signed build and relaunches. Vane → Check for Updates… asks now. Releases and notes are on GitHub.
