# Rich favourite previews

Approved approach: 2026-10-12. The user explicitly authorized writing this spec and plan and proceeding without further design approvals.

## Outcome and boundaries
Hover a GitHub, Gmail, or Google Calendar favourite to see recent relevant items and website navigation actions without changing the selected tab. Keep generic link previews independently configurable. No backend, cloud AI, API key, new OAuth grant, private endpoint, or credential export is permitted. macOS 26 remains the minimum.

## Integration decision
Live Folders uses an independently authorized GitHub REST token; it cannot identify the account in the website session and will not supply preview data. Google public APIs require OAuth scopes; website cookies are not API grants. Use a profile-backed WKWebView and narrowly scoped, read-only DOM extraction of the normal user-facing pages. GitHub and Gmail were inspected through their rendered interfaces: GitHub exposes a signed-in dashboard and PR navigation; Gmail exposes inbox rows, Compose and unread labels. Calendar's attempted live inspection did not establish an extractable schedule. Its adapter must fail closed unless structured event links, times and account identity are available. Do not inspect inline application state, session secrets or private network responses.

## Components
FavouritePreviewService recognizes exact HTTPS service hosts and preserves Google account routes. FavouritePreviewAdapter provides service entry URL, extraction script and validated parsing into a common snapshot. FavouritePreviewCache owns bounded memory-only entries by profile, service, account route and verified account identity. FavouritePreviews coordinates one active load across windows, cancellation, refresh cooldowns, cookie observation and invalidation. FavouritePreviewCard and its tile modifier provide native interaction and presentation.

## Data and privacy
Extract at most five items: GitHub open PR title, repo and available visible review/check labels; Gmail sender, subject and unread state; Calendar title, explicit time and actual event/meeting links. No bodies, descriptions or attachments. Validate all navigation URLs; reject non-HTTPS, credentials and unrelated service item hosts. Meeting links are actual HTTPS links from the event, never invented. Account identity must be explicit before content or empty states are accepted. Unknown markup, incomplete rows, missing account identity or uncertain empty results become unavailable. No content logging or disk cache.

Cache lifetime: fresh for 120 seconds, stale for up to 10 minutes, maximum 12 entries. Minimum automatic refresh spacing 30 seconds; a request has an 8-second deadline and bounded DOM retries, with no background polling. Cookie-store notifications invalidate the profile's cached identity/content without reading cookies. Clearing website data invalidates before removal and after completion, preventing in-flight repopulation; deletion and erase-all also invalidate. Disabling previews cancels work and clears content. Private favourites use fallback only: the generic preview loader creates a distinct ephemeral store and cannot represent the private window's session.

## Interaction
250ms hover dwell and 180ms leave grace. The pointer may enter the card without dismissal. Keyboard access via a Preview command on the focused tile and context menu; VoiceOver exposes Show Preview. Escape dismisses and returns keyboard focus to the tile. Native buttons have visible keyboard focus. Selecting an item opens a new tab through the owning TabStore; Compose opens Gmail's compose website route without sending. Loading, signed out, stale, verified empty and unavailable are distinct. Every state has Open Site; Gmail also has Compose. Appearance and state transitions use Look.quick and vaneMotionPolicy, with immediate changes for Reduce Motion and Battery Saver. Global and per-service switches live in Previews Settings.

## Validation and delivery
Use focused XCTest fixtures for service routing, hostile URLs, parser success/empty/failure/sign-out, account/profile cache isolation, expiry, invalidation, cancellation and request replacement. Execute extraction JavaScript in real WKWebView fixture documents. Build a task-owned signed app with isolated data; check hover dwell, pointer transfer, Escape, keyboard preview and navigation. Record bundle path, PID and start time and terminate only that instance after merge. Report live flows separately from fixtures; do not claim authenticated parsing without a successful service run. Push a codex branch, open PR, obtain independent review of latest diff, resolve findings, wait for required CI, squash-merge and verify the merge.
