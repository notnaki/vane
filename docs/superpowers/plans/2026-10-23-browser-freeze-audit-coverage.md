## Resolved acceptance items

- **Arc sidecar persistence (`5b0f038`).** The production chooser reaches `ArcImport.apply` → `applyAccepted` → awaited `write(space:into:counts:)` → `saveImportedTitles` → `Suspension.SpaceState.saveAsync`. No synchronous `SpaceState.save` call remains in Arc import. The helper reports sidecar failure instead of ignoring it and refreshes already-created Space metadata. Its regression holds an earlier session-lane operation, verifies the Arc writer yields the input actor while awaiting durability, then verifies saved title bytes after release. This exercises the helper used by production; it does not drive the chooser or a complete real Arc profile import. Execution of the current regression is root-owned.
- **Update health timing (`6b6eefa`).** Ordinary backup flushing no longer calls `Updater.markHealthyLaunchAsync`. Source tracing finds the remaining calls only in the five-second startup health task, accepted termination and the quiescent restore handoff. Restore rechecks Store/import/password pending work after the health await before exiting. The timing integration correction is verified by call-site inspection; existing `BackupWorkerTests` cover worker responsiveness and rollback retention during verification, but there is no dedicated automated five-second scheduling regression.
