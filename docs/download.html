Make yourself at home.

  1. Open the latest release and download the available Mac installer.
  2. Open the downloaded disk image and move Vane to Applications.
  3. Launch Vane and bring over your bookmarks and history.
How do I bring over my data?

Import bookmarks and history from Arc, Safari, Firefox, Chrome, and other supported browsers. Passwords can be imported from a CSV export.

See the import guide
Can I build Vane myself?

Yes. From a checkout of the source on macOS 26 or later, build the release and app bundle:

swift build -c release && ./make-app.sh

Read the build guide
