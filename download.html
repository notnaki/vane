Get the latest Vane

Vane is in active development. Download the current published build and review its notes. The features and guide pages describe current development and may include changes awaiting the next release.

View latest release

In active development. Free and open source, for macOS 26 or later.

Make yourself at home.

  1. Open the latest release and download the available Mac installer.
  2. Open the downloaded disk image and move Vane to Applications.
  3. Launch Vane and bring over your bookmarks and history.

Questions

How do I bring over my data?

Import bookmarks and history from Arc, Safari, Firefox, Chrome, and other supported browsers. Passwords can be imported from a CSV export.

See the import guide
Can I build Vane myself?

Yes. From a checkout of the source on macOS 26 or later, build the release and app bundle:

swift build -c release && ./make-app.sh

Read the build guide
Where can I follow development?

Read the current development overview for upcoming changes. Published release notes describe the build you can download; the readiness tracker records compatibility limits.
