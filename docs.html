The Vane guide

Get started, bring over your bookmarks, and find your way around Vane. This guide follows current development on main; older published releases may differ.

Getting started

  • Install. Download the DMG from the latest release, drag Vane to Applications, and open it. Vane is in active development; review the release notes and distribution status before installing. Requires macOS 26 or later.
  • Default browser. Stable Developer ID builds offer the default-browser prompt once; local, debug, and prerelease builds skip it. Use Make Vane Default… in Settings later. External-link settings choose whether links from other apps open in Little Vane or a main window.
  • Address bar. ⌘L or ⌘T opens the bar over the page. It decides between navigation and search: bare hosts, localhost:3000, IPs, file paths and ~/ paths navigate; anything else searches. A leading !g, !ddg, !b picks a search engine for that one query. Suggestions come from history and bookmarks, and typing the start of a site you have visited completes its address inline; Return opens it.
  • Settings. ⌘, opens the Settings window. Passwords, Privacy and Security, Search Engines and Extensions open as Settings pages in a browser tab instead. The arrow rows and Search Settings… in Settings → Profiles open the first three, and Manage Extensions… opens Extensions. Type vane:// in the command bar to list them all; vane://settings and vane://extensions go straight there. Every page but Search Engines has a profile menu, which changes only that tab. Typing settings in the command bar still opens the Settings window.
  • Coming from another browser? Onboarding shows discovered sources, scan progress, and item counts before you confirm an import. Use the dedicated Arc importer for supported Spaces, pins, splits, passwords, and sessions, or the general importer for bookmarks and history.

Import from Arc

Choose Vane → Import from Arc… for the dedicated local migration. Review the detected source and destination before confirming. Supported imports include Spaces, folders, favourites, pinned tabs and split layouts, history, bookmarks, passwords, and cookies. Recognized Arc Space icons are preserved.

Supported credentials and sessions may need access to Arc’s Safe Storage key in macOS Keychain. Existing Vane credentials and cookies are kept. Damaged or unsupported items are reported; available pages from unsupported split layouts are kept as ordinary tabs. Supported Air Traffic Control rules can be reviewed with the import.

The source is read-only. Copied cookies do not guarantee sign-in: site storage, device-bound credentials, passkeys, or the website itself may require another login. Keep the original data until you have checked your sites. The import guide records supported formats and limits.

Other imports

Vane → Import History & Bookmarks… finds supported Chrome, Chromium, Edge, Brave, Vivaldi, Opera, Arc, Firefox, and Safari profiles. Review the discovered source before confirming. macOS privacy controls can block a location; unavailable sources are reported.

The menu importer offers Also copy cookies / sessions, off by default, for supported Chromium profiles. Onboarding’s general-browser route copies bookmarks and history; use the menu importer for optional sessions. Supported macOS v10 cookie encryption can require that browser’s Keychain consent. Firefox and Safari session extraction are not supported; unsupported encryption is reported.

Use Import Passwords… in the Passwords UI for supported browser or password-manager CSV exports. CSV files contain plaintext secrets: protect the export and remove it when no longer needed. See all import and export details.

The sidebar

Top to bottom: the address pill, the Favourites grid, the Space's name, its Pinned section, the Tidy | Clear divider, the Today tabs, and the footer with the Space dots.

  • Address pill. Move the pointer over the sidebar to show the pill's pinned extensions, Copy Link and Site Controls, and Today's Clear. They fade out again when the pointer leaves.
  • Site Controls, the sliders button at the end of the pill, holds one site's controls. Share, Boost, Capture and Reader tiles sit above a tile for each installed extension: click one to run it, or to turn it on if it is off. Right-click an extension for Can Read and Change This Site, Options, Pin to Address Bar, Remove from Vane… and Manage Extension…. The + tile opens the Chrome Web Store. Below, a Settings list shows only what this site has an answer for, such as Developer Mode, a camera decision, zoom, or Block Ads turned off; click a row to change it. The ⋯ menu has Clear Site Data…, Translate and Offer to Translate, Manage Extensions…, Filter Lists and Diagnostics… and Site Settings…, which lists every permission and setting for the site.
  • Favourites are the tiles at the top. They belong to the profile, so they stay put while you switch Spaces. Drag a row onto the grid to make one; drag a tile back into the list to remove it. Closing a favourite (⌘W) sends it back to the page it was favourited at rather than closing it.
  • Pinned tabs live between the Space name and the divider. A pinned row keeps the name it was pinned under, whatever page it wanders to. Hover the favicon of a wandered row and it becomes a return arrow: click it to go back to the pinned page. The × is a two-step: first press sends the row home, second press unpins it. To make the page a row is on its new pinned page, choose Replace Pinned URL with Current in the row's menu.
  • Folders can hold rows in Pinned and in Today. Nest them, fold them, rename them, drag rows in and out. Dragging a whole folder across the divider moves its tabs between Pinned and Today.
  • Today tabs are the ordinary ones. They auto-archive after a while; the Archive is in the Library (⇧⌘L). Clear archives them; Tidy first offers a review of proposed groups, with editable names and page choices. Choose Apply Groups to confirm. Settings → Max controls preview-before-tidying and the grouping connection; Undo Tidy Tabs reverses the grouping.
  • Renaming. Double-click a row to rename it. A name you type wins over everything and survives an unpin. "Use the Page's Own Title" in the row's menu removes it.
  • Toolbar. View → Show Toolbar (⇧⌘D) adds a slim strip to the top of the page with Back, Forward and Reload, the page's host, and Copy Link, pinned extensions and Page Actions. The buttons and address move there from the top of the sidebar. In Split View each pane gets its own strip. It applies to every browser window; Little Vane and Peek keep their own bar.
  • Interface style. Settings → General → Interface style offers Streamlined, a denser sidebar and command bar. It starts on Default, and a change applies the next time Vane opens.

Spaces

  • Switching. Swipe horizontally on the sidebar with two fingers, use ⌥⌘→ / ⌥⌘←, ⌃1–⌃9, or click a dot in the footer. The page changes the moment the swipe commits.
  • Creating. On the last Space, keep pulling left: a plus at the sidebar's edge fills, then the circle behind it fills solid, and you land on Create a Space with a name field, a profile, and a theme. Swipe right or press ⎋ to cancel. Spaces → New Space… does the same from the menu.
  • Order. Spaces have one order across all profiles, which swipes, the footer and the Spaces menu follow. Drag a Space's footer button onto another, or a card's handle in Spaces → Manage Spaces…, to move it. Reordering never changes which profile owns a Space. The order syncs over iCloud while both Spaces and Sidebar folders are on. A card's … menu also has Delete Space…, which asks first and archives its tabs.
  • Theme. Right-click the Space name or its dot for the theme editor: colours, a gradient, grain, and light or dark. The whole window takes the colour.
  • Kept alive. A window keeps the Spaces it has visited loaded behind the one on screen, so swiping back puts the same pages in front of you. Idle pages are unloaded on the usual clock and restore their saved page state where supported. To keep a site loaded, add it to Settings → Advanced → Performance → Keep these sites loaded; its tabs are never put to sleep, even in a Space you have switched away from, in Battery Saver, or under memory pressure. The list applies to every profile and only keeps pages that are already loaded.
  • Library. ⇧⌘L opens Spaces, Archived Tabs, Downloads, Reading Queue, and other saved items. In Downloads, Archived Tabs, and Reading Queue, Filter opens profile choices and section filters. Regular windows can view items across profiles; private windows show only their own items.

Live Folders

A Live Folder is a pinned folder that fills itself. Today it has one source: GitHub pull requests.

  • Make one from the Space name's menu or the dot's menu: New Live Folder…. The first time, Vane signs you in to GitHub in a tab; one click, no token to paste. A build from source without the OAuth secret asks for a personal access token instead.
  • What it shows. Every open pull request you are involved in, or one repository's, optionally only the recent ones. Rows appear and vanish as pull requests open and close; a row you take out stays out. Each row is named after its pull request.
  • Refresh. Every five minutes, when the folder is unfolded, and on Refresh Now. A folder that GitHub refuses says so in a toast; if GitHub has revoked the sign-in Vane forgets it and Edit Live Folder offers to connect again.

Little Vane and splits

  • Little Vane (⌥⌘N) is a small single-page window for a quick look, the way a link from another app opens. Its menu can move the page into your main window. Turn on Settings → Links → Auto-hide toolbar in Little Vane and Peek to let the page fill the window; move the pointer to the top edge to show the toolbar.
  • Split view. ⌃⇧+ puts a second page beside the current one; up to four panes in one card, one row in the sidebar. ⌃⇧N moves between panes and ⌃⇧_ removes the split.
  • Picture in picture (⌥⌘P) detaches the page's video; a tab playing in that window is never unloaded. With Settings → Advanced → Media and Notifications → Automatically enter Picture in Picture on, switching tabs detaches a playing video with sound. Muted videos, such as decorative autoplay loops, stay in the page.
  • Pause All Media, in the View menu and the command bar, pauses every playing video and audio player in every loaded tab, across windows, Spaces and profiles. It only pauses, and leaves live calls alone. It has no shortcut until you assign one in Settings → Shortcuts.
  • Reader (⌥⌘R) shows the article alone, with adjustable size and a serif toggle.

Reading and visual tools

Reader (⌥⌘R) removes page clutter and offers type and size controls. Save supported articles to the Reading Queue for offline reading; a saved article’s metadata and offline content have independent iCloud choices.

Translate Page. Choose View → Translate Page, Page Actions, Site Controls, or the command bar to translate the page in place into your first preferred macOS language. Translation runs on your Mac through Apple’s Translation framework; page text is not sent to a translation service. If a language is not downloaded yet, macOS asks first. Show Original, in the same places, restores the text. When a page loads in another language, a Translate this page? card offers Translate, Not now, or Never Translate This Site; turn Offer to Translate back on in Site Controls. Form fields, code, and text inside frames are left as they are, and text the page adds later stays untranslated.

Page capture. ⌘⇧2 or File → Capture a Portion of This Page lets you choose an element or drag a region. Full Page captures the rendered document. Copy, save, share, edit, or keep the result in Library → Media.

Easels combine notes, drawings, captures, and live web views. ⌥⌘E creates one; export a board as JSON or PNG. Boost, in Site Controls, opens a panel over the page that restyles the site: a colour pad, contrast, brightness and saturation, fonts, text Size and Case, Zap to hide an element (Zap this or Zap all related elements), and a Code view for your own CSS and JavaScript. Space templates reuse a saved setup. Scripts and imported executable content require local approval. See reading and customization.

Max and previews

AI features start off until you enable them in onboarding or Settings → Max. Choose a separate connection for tab titles, tab grouping, download names, page summaries, and Ask on Page. Apple is the on-device option; Add Connection supports your own API keys or an eligible ChatGPT connection. Adding a connection does not select it for every feature.

Ask on Page. Press ⌘F and choose the sparkles button in the find bar, or choose Ask on Page in the command bar, to ask a question about the page you are reading. Ask follow-ups in the same field; ⎋ closes the bar and clears the conversation. Answers come from the page’s extracted text and can still be wrong. Ask on Page uses Apple’s on-device model until you choose a cloud connection for it, and private windows only ever use the on-device model.

Turn on Settings → General → Previews → Preview links on hover to see a destination’s title, screenshot, and description before opening it. When Max and the chosen summary connection are available, a short summary can follow. Battery Saver pauses link previews; an unavailable summary leaves the ordinary preview visible.

Cloud connections send the metadata needed for naming/grouping; cloud page summaries also send bounded extracted page text to the selected provider, and cloud Ask on Page sends your question, earlier questions and answers about the page, and bounded page text. Private windows do not use these cloud AI features. Keys and ChatGPT tokens live in Keychain; ChatGPT account eligibility, plan limits, or API-provider charges still apply. There is no automatic switch to API-key billing. See AI privacy and connection setup.

Favourite previews for GitHub, Gmail, and Calendar use the favourite’s website session and have separate preview controls. They are independent of cloud AI and Live Folders credentials. With a favourite focused, ⌥↓ opens its preview; Escape dismisses it.

Passwords

Manage saved accounts on the Passwords settings page, which opens in a tab. Choose Vane → Passwords → Manage Saved Passwords…, the Passwords row in Settings → Profiles, or type vane://settings/passwords. Its profile menu picks whose accounts it shows. Search, sort, add, edit, reveal, copy, or delete credentials and generate passwords. macOS authentication protects sensitive actions. Each regular profile keeps its own local Keychain credentials; private windows do not use or save them.

Require Touch ID to view passwords is on to start with. The page opens with Touch ID, the way a locked folder does; Use Password… asks for your Mac login password instead. It locks again after five minutes without use, when you leave the page or close its tab, and when the screen locks or the Mac sleeps. Deleting an account shows Undo for five seconds; ⌘Z works too.

Autofill works on matching HTTPS forms and never submits them. ⌥⌘L fills the focused form; a chooser appears when several accounts match. Filling a password asks for Touch ID or your login password first; one prompt covers every tab for five minutes. To stop asking, turn off Require Touch ID to fill passwords on the Passwords page; it applies to the whole app. Dynamic and username-first forms are supported within the documented origin and field checks. Saving a submitted password is a reviewable suggestion, not proof of a successful login.

Offer to save passwords can be turned off per profile without disabling saved-password autofill or manual imports. Provisioned builds offer a separate, initially unselected iCloud Keychain control. Passkeys use the macOS passkey sheet in builds signed with Apple’s passkey entitlement; the ⓘ beside the Password Manager heading says whether your build has it. Sign in with a passkey using Touch ID, the same way as in Safari. Read the password manager guide.

iCloud choices

In an explicitly provisioned build, open Settings → iCloud, review the categories, then enable sync on that Mac. Sync starts off. Ordinary local builds keep it unavailable. Profiles, Spaces, bookmarks, selected saved content, preferences, and other chosen library categories use your Apple Account’s private CloudKit database.

History, extension sync data, passwords, and API keys start unselected; Select All explicitly includes them. Passwords and API keys use separate iCloud Keychain mirrors. Private browsing, website cookies and sign-ins, GitHub credentials, ChatGPT tokens, permissions, and file grants remain local. Download history can sync; downloaded file bytes, paths, and resume data do not.

Other Macs’ tabs appear as device-labelled lists; opening one creates a local tab. Turning sync off keeps existing local and cloud copies. Remove iCloud Data is a separate confirmed action. Account changes pause sync until you approve merging. Cross-Mac convergence and Keychain propagation remain unverified. Read the privacy boundaries and provisioning requirements.

Privacy and blocking

Read the privacy policy for local data, outgoing requests, optional services, retention, and contact information.

  • Ad and tracker blocking uses WebKit rules and a supported subset of EasyList. It starts on per profile. The Content Blocking section of the Privacy and Security settings page (vane://settings/privacy) offers disk imports, opt-in linked local files, and HTTPS subscriptions. Unsupported rules are reported; failed updates keep the last accepted list. Filter Lists and Diagnostics… in Site Controls' ⋯ menu opens it, and Block Ads in Site Settings turns blocking off for one site.
  • Website data. Website Data and Clear Browsing Data are on the Privacy and Security page and in Settings → Profiles. Clear Site Data… in Site Controls' ⋯ menu clears only the current site.
  • Private windows (⇧⌘N) get a data store that is never written to disk.
  • Camera and microphone are asked per site and remembered per origin and profile; Reset Camera & Microphone Permissions… forgets them.
  • Certificates. A bad certificate shows a two-step alert with the fingerprint; an exception is tied to that exact certificate, so a swapped one asks again.
  • Profiles separate website stores, history, bookmarks, saved passwords, extensions, and Spaces. Download and media records are shared across regular profiles; Library labels preserve item ownership. Private windows keep their own temporary context. Saving or exporting a file still writes the output you choose.

Developer

  • Extensions. Use Add to Vane on a Chrome Web Store detail page, or Extensions → Install from Chrome Web Store… to paste a store link or ID. Vane verifies download signatures and asks you to review access; the review warns when an extension asks for something Vane or WebKit does not support. Extensions → Manage Extensions… opens the Extensions page in a tab (vane://extensions), with a profile menu; each profile has its own set. Install from a folder or Safari app… there accepts unpacked MV2/MV3 folders and signed Safari extension apps. Compatibility depends on WebKit and Vane’s supported APIs.
  • Chrome extension APIs. Vane adds some Chrome APIs that WebKit lacks: side panels, docked to the right of the page; web sign-in through chrome.identity; tab groups, which become folders in Today; and page control through chrome.debugger, for the tab on screen, with a pill at the foot of the page to Stop it. AdBlock and uBlock block requests, though a large rule list can take a minute or so after install before blocking starts. Native messaging, notifications and downloads are not supported. See the extension compatibility notes.
  • Performance diagnostics. Settings → Advanced → Performance → Diagnostics shows launch time, main-thread hangs and Space switch times measured on this Mac, and how many of Apple's hang and crash reports are saved. Nothing is sent. Export… saves an anonymous file; Include Mac details in exports adds your Mac model, macOS version, memory, core count and binary identifiers. Clear removes the data. See diagnostics and privacy.
  • Inspector. Web Inspector (⌥⌘I), JavaScript console (⌥⌘C), View Source (⌥⌘U), a user-agent picker, and Allow Web Inspector for pages.
  • Build from source. swift build -c release && ./make-app.sh on macOS 26. ./.build/release/vane selfcheck --pure runs the offline checks. The development guide has the rest.

Updates

Vane → Check for Updates… checks the selected channel now. Stable is the default; Settings → General → Updates → Update channel offers Nightly for early builds. Both channels use the same app and data. Returning to Stable waits for a newer stable version rather than downgrading.

Automatic checks can be disabled. Available updates use the shared progress pill for download, installation, and relaunch. Nightly publication is checked daily but only publishes an eligible checked revision; it is not a promise of a build every night. Stable releases are deliberate. Read the published release notes for what is actually available, and the current development overview for the upcoming version.
