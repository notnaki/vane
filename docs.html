Getting started

  • Install. Download the DMG from the latest release, drag Vane to Applications, and open it. Vane is in active development; review the release notes and distribution status before installing. Requires macOS 26 or later.
  • Default browser. Stable Developer ID builds offer the default-browser prompt once; local, debug, and prerelease builds skip it. Use Make Vane Default… in Settings later. External-link settings choose whether links from other apps open in Little Vane or a main window.
  • Address bar. ⌘L or ⌘T opens the bar over the page. It decides between navigation and search: bare hosts, localhost:3000, IPs, file paths and ~/ paths navigate; anything else searches. A leading !g, !ddg, !b picks a search engine for that one query. Suggestions come from history and bookmarks, and typing the start of a site you have visited completes its address inline; Return opens it.
  • Coming from another browser? Onboarding shows discovered sources, scan progress, and item counts before you confirm an import. Use the dedicated Arc importer for supported Spaces, pins, splits, passwords, and sessions, or the general importer for bookmarks and history.

The sidebar

Top to bottom: the address pill, the Favourites grid, the Space's name, its Pinned section, the Tidy | Clear divider, the Today tabs, and the footer with the Space dots.

  • Favourites are the tiles at the top. They belong to the profile, so they stay put while you switch Spaces. Drag a row onto the grid to make one; drag a tile back into the list to remove it. Closing a favourite (⌘W) sends it back to the page it was favourited at rather than closing it.
  • Pinned tabs live between the Space name and the divider. A pinned row keeps the name it was pinned under, whatever page it wanders to. Hover the favicon of a wandered row and it becomes a return arrow: click it to go back to the pinned page. The × is a two-step: first press sends the row home, second press unpins it.
  • Folders can hold rows in Pinned and in Today. Nest them, fold them, rename them, drag rows in and out. Dragging a whole folder across the divider moves its tabs between Pinned and Today.
  • Today tabs are the ordinary ones. They auto-archive after a while; the Archive is in the Library (⇧⌘L). Clear archives them; Tidy first offers a review of proposed groups, with editable names and page choices. Choose Apply Groups to confirm. Settings → Max controls preview-before-tidying and the grouping connection; Undo Tidy Tabs reverses the grouping.
  • Renaming. Double-click a row to rename it. A name you type wins over everything and survives an unpin. "Use the Page's Own Title" in the row's menu removes it.

Spaces

  • Switching. Swipe horizontally on the sidebar with two fingers, use ⌥⌘→ / ⌥⌘←, ⌃1–⌃9, or click a dot in the footer. The page changes the moment the swipe commits.
  • Creating. On the last Space, keep pulling left: a plus at the sidebar's edge fills, then the circle behind it fills solid, and you land on Create a Space with a name field, a profile, and a theme. Swipe right or press ⎋ to cancel. Spaces → New Space… does the same from the menu.
  • Theme. Right-click the Space name or its dot for the theme editor: colours, a gradient, grain, and light or dark. The whole window takes the colour.
  • Kept alive. A window keeps the Spaces it has visited loaded behind the one on screen, so swiping back puts the same pages in front of you. Idle pages are unloaded on the usual clock and restore their saved page state where supported.
  • Library. ⇧⌘L opens Spaces, Archived Tabs, Downloads, Reading Queue, and other saved items. In Downloads, Archived Tabs, and Reading Queue, Filter opens profile choices and section filters. Regular windows can view items across profiles; private windows show only their own items.

Live Folders

A Live Folder is a pinned folder that fills itself. Today it has one source: GitHub pull requests.

  • Make one from the Space name's menu or the dot's menu: New Live Folder…. The first time, Vane signs you in to GitHub in a tab; one click, no token to paste. A build from source without the OAuth secret asks for a personal access token instead.
  • What it shows. Every open pull request you are involved in, or one repository's, optionally only the recent ones. Rows appear and vanish as pull requests open and close; a row you take out stays out. Each row is named after its pull request.
  • Refresh. Every five minutes, when the folder is unfolded, and on Refresh Now. A folder that GitHub refuses says so in a toast; if GitHub has revoked the sign-in Vane forgets it and Edit Live Folder offers to connect again.

Import from Arc

Choose Vane → Import from Arc… for the dedicated local migration. Review the detected source and destination before confirming. Supported imports include Spaces, folders, favourites, pinned tabs and split layouts, history, bookmarks, passwords, and cookies. Recognized Arc Space icons are preserved.

Supported credentials and sessions may need access to Arc’s Safe Storage key in macOS Keychain. Existing Vane credentials and cookies are kept. Damaged or unsupported items are reported; available pages from unsupported split layouts are kept as ordinary tabs. Supported Air Traffic Control rules can be reviewed with the import.

The source is read-only. Copied cookies do not guarantee sign-in: site storage, device-bound credentials, passkeys, or the website itself may require another login. Keep the original data until you have checked your sites. The import guide records supported formats and limits.

Other imports

Vane → Import History & Bookmarks… finds supported Chrome, Chromium, Edge, Brave, Vivaldi, Opera, Arc, Firefox, and Safari profiles. Review the discovered source before confirming. macOS privacy controls can block a location; unavailable sources are reported.

The menu importer offers Also copy cookies / sessions, off by default, for supported Chromium profiles. Onboarding’s general-browser route copies bookmarks and history; use the menu importer for optional sessions. Supported macOS v10 cookie encryption can require that browser’s Keychain consent. Firefox and Safari session extraction are not supported; unsupported encryption is reported.

Use Import Passwords… in the Passwords UI for supported browser or password-manager CSV exports. CSV files contain plaintext secrets: protect the export and remove it when no longer needed. See all import and export details.

Passwords

Manage saved accounts in Settings → Passwords. Search, sort, add, edit, reveal, copy, or delete credentials and generate passwords. macOS authentication protects sensitive actions. Each regular profile keeps its own local Keychain credentials; private windows do not use or save them.

Autofill works on matching HTTPS forms and never submits them. ⌥⌘L fills the focused form; a chooser appears when several accounts match. Dynamic and username-first forms are supported within the documented origin and field checks. Saving a submitted password is a reviewable suggestion, not proof of a successful login.

Offer to save passwords can be turned off per profile without disabling saved-password autofill or manual imports. Provisioned builds offer a separate, initially unselected iCloud Keychain control. Passkeys still require Apple’s managed entitlement and provisioning; Developer ID signing alone is insufficient. Read the password manager guide.

iCloud choices

In an explicitly provisioned build, open Settings → iCloud, review the categories, then enable sync on that Mac. Sync starts off. Ordinary local builds keep it unavailable. Profiles, Spaces, bookmarks, selected saved content, preferences, and other chosen library categories use your Apple Account’s private CloudKit database.

History, extension sync data, passwords, and API keys start unselected; Select All explicitly includes them. Passwords and API keys use separate iCloud Keychain mirrors. Private browsing, website cookies and sign-ins, GitHub credentials, ChatGPT tokens, permissions, and file grants remain local. Download history can sync; downloaded file bytes, paths, and resume data do not.

Other Macs’ tabs appear as device-labelled lists; opening one creates a local tab. Turning sync off keeps existing local and cloud copies. Remove iCloud Data is a separate confirmed action. Account changes pause sync until you approve merging. Cross-Mac convergence and Keychain propagation remain unverified. Read the privacy boundaries and provisioning requirements.

Privacy and blocking

Read the privacy policy for local data, outgoing requests, optional services, retention, and contact information.

  • Ad and tracker blocking uses WebKit rules and a supported subset of EasyList. It starts on per profile. Settings → Privacy and Security → Content Blocking offers disk imports, opt-in linked local files, and HTTPS subscriptions. Unsupported rules are reported; failed updates keep the last accepted list.
  • Private windows (⇧⌘N) get a data store that is never written to disk.
  • Camera and microphone are asked per site and remembered per origin and profile; Reset Camera & Microphone Permissions… forgets them.
  • Certificates. A bad certificate shows a two-step alert with the fingerprint; an exception is tied to that exact certificate, so a swapped one asks again.
  • Profiles separate website stores, history, bookmarks, saved passwords, extensions, and Spaces. Download and media records are shared across regular profiles; Library labels preserve item ownership. Private windows keep their own temporary context. Saving or exporting a file still writes the output you choose.

Little Vane and splits

  • Little Vane (⌥⌘N) is a small single-page window for a quick look, the way a link from another app opens. Its menu can move the page into your main window.
  • Split view. ⌃⇧+ puts a second page beside the current one; up to four panes in one card, one row in the sidebar. ⌃⇧N moves between panes and ⌃⇧_ removes the split.
  • Picture in picture (⌥⌘P) detaches the page's video; a tab playing in that window is never unloaded.
  • Reader (⌥⌘R) shows the article alone, with adjustable size and a serif toggle.

Reading and visual tools

Reader (⌥⌘R) removes page clutter and offers type and size controls. Save supported articles to the Reading Queue for offline reading; a saved article’s metadata and offline content have independent iCloud choices.

Page capture. ⌘⇧2 or File → Capture a Portion of This Page lets you choose an element or drag a region. Full Page captures the rendered document. Copy, save, share, edit, or keep the result in Library → Media.

Easels combine notes, drawings, captures, and live web views. ⌥⌘E creates one; export a board as JSON or PNG. Boosts customize a site’s appearance, and Space templates reuse a saved setup. Scripts and imported executable content require local approval. See reading and customization.

Max and previews

AI features start off until you enable them in onboarding or Settings → Max. Choose a separate connection for tab titles, tab grouping, download names, and page summaries. Apple is the on-device option; Add Connection supports your own API keys or an eligible ChatGPT connection. Adding a connection does not select it for every feature.

Turn on Settings → General → Previews → Preview links on hover to see a destination’s title, screenshot, and description before opening it. When Max and the chosen summary connection are available, a short summary can follow. Battery Saver pauses link previews; an unavailable summary leaves the ordinary preview visible.

Cloud connections send the metadata needed for naming/grouping; cloud page summaries also send bounded extracted page text to the selected provider. Private windows do not use these cloud AI features. Keys and ChatGPT tokens live in Keychain; ChatGPT account eligibility, plan limits, or API-provider charges still apply. There is no automatic switch to API-key billing. See AI privacy and connection setup.

Favourite previews for GitHub, Gmail, and Calendar use the favourite’s website session and have separate preview controls. They are independent of cloud AI and Live Folders credentials. With a favourite focused, ⌥↓ opens its preview; Escape dismisses it.

Keyboard shortcuts

Every one of these can be rebound in Settings → Keyboard. AppKit's own chords (⌘C, ⌘Q, ⌘H and friends) are left alone. ⇧⌘P searches commands by name or by shortcut.

Developer

  • Extensions. Use Add to Vane on a Chrome Web Store detail page, or Extensions → Install from Chrome Web Store… to paste a store link or ID. Vane verifies download signatures and asks you to review access. The manager also accepts unpacked MV2/MV3 folders and signed Safari extension apps, one set per profile. Compatibility depends on WebKit and Vane’s supported APIs.
  • Inspector. Web Inspector (⌥⌘I), JavaScript console (⌥⌘C), View Source (⌥⌘U), a user-agent picker, and Allow Web Inspector for pages.
  • Build from source. swift build -c release && ./make-app.sh on macOS 26. ./.build/release/vane selfcheck --pure runs the offline checks. The development guide has the rest.

Updates

Vane → Check for Updates… checks the selected channel now. Stable is the default; Settings → General → Updates → Update channel offers Nightly for early builds. Both channels use the same app and data. Returning to Stable waits for a newer stable version rather than downgrading.

Automatic checks can be disabled. Available updates use the shared progress pill for download, installation, and relaunch. Nightly publication is checked daily but only publishes an eligible checked revision; it is not a promise of a build every night. Stable releases are deliberate. Read the published release notes for what is actually available, and the current development overview for the upcoming version.
